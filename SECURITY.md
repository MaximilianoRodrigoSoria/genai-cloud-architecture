# Política de seguridad

## Reportar una vulnerabilidad
Si encontrás una vulnerabilidad, escribí a **maximilianorodrigosoria@gmail.com**
o abrí un issue con la etiqueta `security` **sin incluir detalles de explotación**.
Respondo a la brevedad y coordino la divulgación responsable.

## Alcance
Este repositorio es una pieza de portfolio con una implementación de referencia.
No lo despliegues en producción sin una revisión de seguridad propia (IAM, redes, secretos).
